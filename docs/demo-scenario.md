# Демонстраційний сценарій (захист проєкту)

Тривалість — 7–8 хвилин. Відкрийте `index.html` на проєкторі.
Щоб почати з чистих даних: роль «Адміністратор» → «Налаштування» → «Скинути всі демо-дані».

Натисніть **«▶ Демо-сценарій»** (або відкрийте `index.html#tour`):

| Крок | Що показує |
|---|---|
| 1 | 3D-корпус: блоки А і Б по 5 поверхів, перемичка |
| 2 | Поверх 0: адміністративне приміщення, серверна, електрощитова |
| 3 | Статуси аудиторій на 2-му поверсі, картка аудиторії |
| 4 | Вкладка «Сценарії»: правила з пріоритетами, карта «Активний сценарій» |
| 5 | Ручний сценарій «Презентація» на 90 хв |
| 6 | Автовимкнення в порожніх аудиторіях |
| 7 | Комутація: виділено зчитувач відбитків на 2-му поверсі блоку А — на плані лише він, його приміщення й траса до шафи ЩА-А2, решта індикаторів прихована |
| 8 | Доступ за відбитком: викладач проходить, невідомий відбиток — відмова |
| 9 | Відключення електроенергії: ДБЖ → ДГУ через АВР, сценарій «Резервне живлення» |
| 10 | Відновлення мережі, графік енергії |
| 11 | Подія безпеки: двері серверної |
| 12 | Реальний розклад ННІФТКН і люди в аудиторіях: вівторок 11:40, режим карти «Присутність людей» |

## Реальний розклад і зайнятість (живий фрагмент)

1. Вкладка «Аудиторії»: джерело — розклад ННІФТКН, зараз 1-й або 2-й тиждень, у таблиці — заняття й **кількість людей з лічильника**.
2. «Розклад групи» → оберіть, наприклад, **424**: обидва тижні, потоки, аудиторії; клік — аудиторія на карті.
3. Відкрийте аудиторію з парою, розгорніть «Люди в аудиторії за день»: люди сходяться до пари, частина запізнюється, на перерві виходять.
4. Наголосіть: PIR бачить тільки рух; кількість рахують лічильники Milesight VS121-P / VS133-P (паспортні дані — у вкладці «Енергія»).
5. «Перевірка конфліктів» показує справжні накладки джерела; «Імпортувати JSON» — оновити розклад без програміста.
