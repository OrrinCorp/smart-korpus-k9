# Демонстраційний сценарій (захист проєкту)

Тривалість — 7–8 хвилин. Відкрийте `index.html` на проєкторі, а `student.html` — на телефоні або в другому вікні.
Щоб почати з чистих даних: роль «Адміністратор» → «Налаштування» → «Скинути всі демо-дані».

Натисніть **«▶ Демо-сценарій»** (або відкрийте `index.html#tour`):

| Крок | Що показує |
|---|---|
| 1 | 3D-корпус: блоки А і Б по 5 поверхів, перемичка |
| 2 | Поверх 0: адміністративне приміщення, серверна, електрощитова |
| 3 | Статуси аудиторій на 2-му поверсі, картка аудиторії |
| 4 | Вкладка «Сценарії»: правила з пріоритетами, карта «Активний сценарій» |
| 5 | Ручний сценарій «Презентація» на 90 хв |
| 6 | Автовимкнення в порожніх аудиторіях |
| 7 | Комутація: виділено зчитувач А-202 — на плані лише він, його приміщення й траса до шафи ЩА-А2, решта індикаторів прихована |
| 8 | Доступ за відбитком: викладач проходить, невідомий відбиток — відмова |
| 9 | Відключення електроенергії: ДБЖ → ДГУ через АВР, сценарій «Резервне живлення» |
| 10 | Відновлення мережі, графік енергії |
| 11 | Подія безпеки: двері серверної |
| 12 | Розклад подій, який бачать студенти |

## Студентський застосунок (живий фрагмент)

1. У `student.html` оберіть групу, наприклад КН-21: на екрані «Сьогодні» — поточна й наступна пара та де аудиторія.
2. На панелі («Події») створіть подію для «Усі» — вона з'явиться в розділі «Події» студента.
3. На панелі надішліть оголошення — воно з'явиться в «Новинах».
4. Наголосіть: студенти **не бачать** датчиків, карти й керування — лише розклад, події, аудиторії та новини.
