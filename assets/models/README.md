# 3D-модель корпусу

Покладіть сюди готову модель під назвою **`korpus9.glb`**.

- Якщо сайт роздається через http(s), модель підвантажиться автоматично.
- Якщо `index.html` відкрито з диска, завантажте модель кнопкою «⬆ 3D-модель» (роль «Адміністратор»).
  Модель збережеться в браузері (IndexedDB) і відкриватиметься сама.

## Вимоги до моделі

| Параметр | Значення |
|---|---|
| Формат | `.glb` (glTF 2.0 binary). Можна `.gltf` з вбудованими ресурсами |
| Одиниці | 1 одиниця = 1 метр, вісь Y — вгору (типовий експорт glTF у Blender) |
| Початок координат | Як у схемі: x — на схід, −z — на північ. Західна стіна блоку А при x = −34, південна при z = +10. Інакше підженіть у «Налаштуваннях» (масштаб, поворот, зсув) |
| Розмір | До ~30 МБ. Draco-стиснення **не** підтримується (у проєкті немає декодера) |
| Аудиторії | Окремий меш або об'єкт на кожну аудиторію з назвою за номером: `А-301`, `A_301`, `room_B-105`, `Б 210`. Латинські A/B/P і кириличні А/Б/П розпізнаються однаково |

Меші з такими назвами стають клікабельними й фарбуються за обраним режимом (статус, CO₂…).
Решта моделі (стіни, дах, рельєф) показується як є.

## Порада для Blender

1. Підкладка: `korpus_terytoriya_3.svg` (масштаб 1 м = 8 px) — File → Import → SVG, масштаб 0.125.
2. Для кожної аудиторії — окремий об'єкт «підлога + об'єм» з назвою за номером.
3. File → Export → glTF 2.0 → формат **glTF Binary (.glb)**, увімкнути «Apply Modifiers».

## Модель окремої кімнати

У режимі «Модель кімнати» (подвійний клік по приміщенню) адміністратор може завантажити свою `.glb` саме для цього приміщення.
Модель автоматично вписується в габарити кімнати (центр — середина кімнати, низ — підлога); пристрої й кабелі
показуються поверх неї. Під час роботи через http можна покласти файли в `assets/models/rooms/` з назвою за номером,
наприклад `assets/models/rooms/А-305.glb`.
